Timing methodology
------------------------------------------------------------------------
1. GPU model-only：先将真实测试 batch 传入 GPU 并完成归一化，再测纯模型 forward；H2D 和 normalization 不计入该项。
2. E2E：每个模型先独立预热，再重新遍历完整 test split；计时包括 DataLoader next、图像 H2D、GPU normalization、GPU forward 和 CUDA synchronize。
3. 正式遍历的第一个 batch 单独记录，不纳入稳态 mean/median/P95；但仍参与完整 test split 的 Dice/IoU。
4. loader_wait 包括 Dataset 的磁盘读取、图像解码和 CPU 预处理；这些操作在当前 Dataset 的 __getitem__ 内执行，无法再无侵入地拆分。
5. masks 留在 CPU；mask H2D 和 Dice/IoU 计算不计入推理耗时。
6. FLOPs 按 2×MACs 估算；不同工具的 FLOPs 统计口径可能不同。
