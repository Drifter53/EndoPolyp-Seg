Timing methodology
------------------------------------------------------------------------
1. 所有模型沿用 V2 的结构、checkpoint、测试集和预处理配置。
2. cuDNN benchmark=True；正式测速前对完整 batch 和尾批 batch shape 分别预热，避免首次遇到尾批 shape 时才进行算法搜索。
3. GPU model-only：H2D 和 normalization 在计时区间之外，只统计模型 forward。
4. E2E：每个 batch 统计 DataLoader next、图像 H2D、GPU normalization、GPU forward 和 CUDA synchronize。
5. 稳态统计只包含 batch size=4 且不是正式遍历首批的记录；首批和不完整尾批单独报告。
6. 所有测试图片（包括尾批）均参与逐图 Dice / IoU；mask 保留在 CPU，指标计算不计入推理耗时。
7. 完整遍历吞吐量包含首批与尾批；稳态吞吐量仅用于完整 batch 比较。
8. FLOPs 按 2×MACs 估算；不同工具的 FLOPs 统计口径可能不同。
9. 尾批预热是针对 V2 异常的诊断性修正；若仍有异常，需继续检查逐 Batch 记录。
